# Lara Viana — site oficial

Website estático e público para divulgar o projeto artístico virtual Lara Viana — DELTΔ MUSIC GROUP.

Site previsto: https://idelta775-hash.github.io/lara-viana-oficial/

- Identidade visual: retrato canônico do projeto, preservando a fonte original.
- Músicas: links do YouTube oficial, sem copiar ou hospedar áudio protegido.
- Sem cookies de rastreamento, formulários, coleta de dados pessoais ou anúncios.
- Redes TikTok, Instagram e Facebook não são exibidas como oficiais enquanto a identidade não for confirmada.
- Datas de próximos lançamentos devem ser confirmadas antes da atualização pública.

Arquivos de produção: `index.html` e `perfil.png`.
